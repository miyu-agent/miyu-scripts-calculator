# Calculator

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `calculator`, which evaluates one or more expressions. Separate several expressions with `;` or a line break.

| Parameter | Description |
|---|---|
| `expression` | The expression. The operators are `+ - * / // %`; both `^` and `**` mean a power. Functions: sin cos tan asin acos atan atan2 sinh cosh tanh sqrt cbrt abs ln log(x[, base]) log2 log10 exp floor ceil round(x[, digits]) trunc factorial gcd lcm comb perm min max hypot degrees radians. Constants: pi e tau inf |
| `angle` | The unit used by the trigonometric functions: `rad` (default) or `deg` |

Integers are computed exactly (`2^100` gives every digit), and floating-point numbers are given to 15 significant digits. `round` rounds half away from zero. If a result is longer than about 30,000 digits, or a factorial is larger than 5000!, the tool does not compute it. The tool does not use `eval` and accepts only the forms listed above. It uses only the standard library and needs no network access.
